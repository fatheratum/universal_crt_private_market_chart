# Universal CRT — Private Market Chart

Terminal multi-chart CRT. Requires a real PTY terminal (Termux-class).

## Run (Termux / Omni terminal)

pkg install python git -y
cd \~
git clone https://github.com/fatheratum/universal_crt_private_market_chart.git
cd universal_crt_private_market_chart
python universal_crt_v3.py

Keys: N F V G Z X T A R Q · arrows · Enter
